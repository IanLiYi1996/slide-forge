# Document Processor 多形状标注工具

## 🎨 支持的标注工具

Document Processor现在支持4种标注工具，帮助用户精确指示AI处理目标。

### 1. ⭕ 圆形 (Circle)
**用途**：标记圆形或椭圆形区域

**操作方法**：
- 点击圆心位置
- 拖动鼠标设置半径
- 释放鼠标完成

**适用场景**：
- 标记人脸、Logo等圆形元素
- 圈出重要数据点
- 突出圆形图表区域

**示例指令**：
```
"增强圆圈内的文字清晰度"
"提取圆圈标记的数据"
```

---

### 2. ⬜ 矩形 (Rectangle)
**用途**：标记矩形区域

**操作方法**：
- 点击左上角
- 拖动到右下角
- 释放鼠标完成

**适用场景**：
- 框选表格
- 标记文本段落
- 突出矩形图片区域

**示例指令**：
```
"提取矩形框内的表格数据"
"裁剪到矩形区域"
"只保留框内内容"
```

---

### 3. ➡️ 箭头 (Arrow)
**用途**：指向特定位置或方向

**操作方法**：
- 点击起点
- 拖动到终点
- 释放鼠标完成
- 自动生成箭头

**适用场景**：
- 指示特定元素
- 标记方向或流程
- 指出问题位置

**示例指令**：
```
"增强箭头指向的区域"
"提取箭头所指的文字"
"修复箭头标记的错误"
```

---

### 4. ✏️ 自由画笔 (Pen)
**用途**：自由绘制任意形状

**操作方法**：
- 点击并按住鼠标
- 自由移动绘制路径
- 释放鼠标完成

**适用场景**：
- 标记不规则形状
- 画出复杂轮廓
- 连接多个元素

**示例指令**：
```
"提取笔画覆盖的区域"
"增强标记路径上的内容"
```

- 🟢 绿色 (#00FF00) - 标记正确/通过
- 🔵 蓝色 (#0000FF) - 信息标记
- 🟡 黄色 (#FFFF00) - 警告/注意
- 🟣 紫色 (#FF00FF) - 重点强调
- 🔷 青色 (#00FFFF) - 补充信息

**交互**：

- 选中的颜色有放大 + ring效果

**滑块调节**：
- 范围：1-10px
- 默认：3px
- 实时显示当前值

**适用场景**：
- 细线(1-3px)：精确标注
- 中线(4-6px)：常规使用
- 粗线(7-10px)：强调重点

### 操作按钮

**Undo** - 撤销最后一个标注
**Clear** - 清除所有标注
**Use Annotated Image (N)** - 完成标注（N=标注数量）

## 💻 技术实现

### 数据结构

```typescript
interface Annotation {
  type: 'circle' | 'rectangle' | 'arrow' | 'pen';
  color: string;
  lineWidth: number;
  points: number[];  // 不同形状的坐标数据
}

// Circle: [centerX, centerY, radius]
// Rectangle: [x1, y1, x2, y2]
// Arrow: [startX, startY, endX, endY]
// Pen: [x1, y1, x2, y2, x3, y3, ...] (路径点)
```

### 绘制算法

**圆形**：
```typescript
const radius = Math.sqrt(
  Math.pow(endX - startX, 2) + Math.pow(endY - startY, 2)
);
ctx.arc(startX, startY, radius, 0, 2 * Math.PI);
```

**矩形**：
```typescript
ctx.rect(x1, y1, x2 - x1, y2 - y1);
```

**箭头**：
```typescript
// 画线
ctx.moveTo(startX, startY);
ctx.lineTo(endX, endY);

// 画箭头（两条线）
const angle = Math.atan2(endY - startY, endX - startX);
const headLength = 20;
// 左边线
ctx.lineTo(
  endX - headLength * Math.cos(angle - Math.PI / 6),
  endY - headLength * Math.sin(angle - Math.PI / 6)
);
// 右边线（回到箭头尖端）
ctx.moveTo(endX, endY);
ctx.lineTo(
  endX - headLength * Math.cos(angle + Math.PI / 6),
  endY - headLength * Math.sin(angle + Math.PI / 6)
);
```

**自由画笔**：
```typescript
ctx.moveTo(points[0], points[1]);
for (let i = 2; i < points.length; i += 2) {
  ctx.lineTo(points[i], points[i + 1]);
}
```

## 📝 AI Prompt增强

### 自动添加的指令

使用标注图片时，系统自动添加：

```
IMPORTANT: Remove any drawn shapes (circles, rectangles, arrows, lines) or annotations from the image.
```

### AI理解能力

**单一形状**：
- 圆形 → 关注圆形区域内容
- 矩形 → 处理矩形框内容
- 箭头 → 关注箭头指向位置
- 画笔 → 理解自由勾勒的区域

**多形状组合**：
- 不同颜色 → 区分不同优先级
- 不同类型 → 理解不同操作意图
- AI会综合理解所有标注

## 🎯 使用技巧

### 技巧1：混合使用多种工具

```
步骤：
1. 用矩形框选主要区域
2. 用圆形标记重点细节
3. 用箭头指示处理方向
4. 用画笔连接相关元素

指令："按箭头方向处理矩形内的内容，重点关注圆圈标记的部分"
```

### 技巧2：颜色编码

```
红色：需要处理的区域
绿色：需要保留的区域
蓝色：需要提取的信息
黄色：需要注意的问题

指令："处理红色区域，保留绿色区域，提取蓝色框内的数据"
```

### 技巧3：精确vs快速

**精确标注**（矩形/圆形）：
- 用于需要明确边界的场景
- AI准确理解区域范围

**快速标注**（画笔/箭头）：
- 用于快速指示大概位置
- AI理解意图即可
